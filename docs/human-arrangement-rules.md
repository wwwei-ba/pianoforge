# 人类转谱（参考谱）的编配规律

参考材料（D:\党）：

- `Piano 脳裏上のクラッカー.pdf`（8 页，128 BPM，4/4，3 个降号）
- `Keyboard 秒針を噛む.pdf`（7 页，130 BPM，4/4，4 个升号）
- `Keyboard ハゼ馳せる果てるまで.pdf`（6 页）

## 观察到的事实

1. **右手 = 旋律 + 内声部**
   旋律保留原始节奏（十六分、附点、三连音），不量化成八分；
   需要时用 `8va` 整体上移八度记谱，而不是把旋律写到上加线。

2. **左手 = 有节奏型的伴奏，不是每拍柱式和弦**
   脳裏上：左手是"低音—和弦—和弦—和弦"的八分分解（阿尔贝蒂式）；
   秒針：左手是八度低音 + 切分和弦，大量休止。

3. **休止是重要的**
   原曲没有声音的地方，谱面写整小节休止（𝄽），不填和弦。

4. **密度**
   每只手通常 1–3 个音同时发声；全曲同时发声很少超过 5 个。

5. **分段**
   每段用一种伴奏型（A 段分解和弦、B 段柱式和弦、C 段变调），并保持到段落结束。

6. **变调与调号**
   段落转调时换调号，不是靠临时记号堆。

## 对自动转谱的直接结论

| 现状 | 应该改成 |
| --- | --- |
| 每八分音符重新击键、和弦铺满 | 用转谱的真实起音与时值，休止就留白 |
| 同时最多 4 个和弦音 + 低音 | 同时 2–3 个音，左手只保留低音与 1–2 个内声部 |
| 旋律量化到八分网格 | 保留十六分精度 |
| 高音旋律写成上加线 | 记谱上移八度（8va） |
| 每小节和弦都不同 | 同一段落内维持伴奏型，只在和声真正变化时换 |
