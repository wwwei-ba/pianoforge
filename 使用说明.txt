PianoForge · 音频转钢琴谱 / 指弹吉他谱 / 钢琴音轨
================================================

【第一次使用】

1. 双击 INSTALL.cmd
   - 需要电脑已安装 Python 3.11 或更高版本（安装 Python 时勾选 Add python.exe to PATH）
   - 脚本会自动创建运行环境并下载依赖，首次约 5-10 分钟
   - 全程需要联网

2. 安装完成后，双击 PianoForge.cmd（或 PianoForge.exe）启动软件

【怎么用】

- 把音乐文件（mp3 / ogg / wav / flac / m4a）直接拖进窗口，点「开始转谱」
- 转谱完成后，每首歌会得到一个文件夹，里面只有四个文件：
    曲谱音频 audio.wav      —— 生成的钢琴演奏
    原曲     original.*     —— 你的原始音频副本
    钢琴谱   piano.pdf      —— 可直接看/打印
    吉他谱   guitar.pdf     —— 指弹六线谱
  可编辑的 MusicXML、MIDI、分析报告都在 _analysis/ 子目录里
- 软件内可播放、可滚轮翻谱；音量会自动记住

【关于速度】

- 一首 4 分钟的歌大约 1.5-3 分钟（取决于电脑性能）
- 第一次转谱会稍慢，因为要下载分离模型

【常见问题】

- 打开软件没反应：先运行 INSTALL.cmd；仍有问题请把 cachegui_error.log 发给作者
- 提示"当前以受限权限运行"：请从桌面图标正常启动，不要从沙箱/受限终端启动
- 转谱效果不理想：软件是初代版本，复杂编曲的曲子会有偏差，欢迎反馈
